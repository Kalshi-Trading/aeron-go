# Migrating from upstream `lirm/aeron-go` master to `parity`

`parity` ports the Java Aeron 1.53.3 client (driver protocol, archive client, ReplayMerge,
PersistentSubscription, cluster client and service) to Go. The module path is unchanged
(`github.com/lirm/aeron-go`). Upstream API shapes are kept wherever a new feature does not need a different one
(see [Restored for compatibility](#restored-for-compatibility)); the breaks below are the ones the 1.53.3 features
require. This guide lists every remaining breaking change found by diffing the exported API of `parity` against
upstream `master` (`golang.org/x/exp/cmd/apidiff`, one package at a time) plus the behaviour changes that compile but
act differently. New packages and additive methods are summarised at the end.

Toolchain: `go.mod` now says `go 1.21` (upstream: `go 1.20`). The media driver must be Aeron 1.53.x:
the cluster schema is v17 and the driver protocol includes commands added after the upstream fork point.

## `aeron`

| Upstream | parity | What to do |
|---|---|---|
| `(*Aeron).AddExclusivePublication(ch, stream) (*Publication, error)` | returns `*ExclusivePublication` | Use `*aeron.ExclusivePublication`, or the `aeron.Publisher` interface for code that takes either kind. Same for `GetExclusivePublication(id)` and the deprecated `AddExclusivePublicationDeprecated` (now `chan *ExclusivePublication`). |
| `(*Aeron).AddCounter(...) (int64, error)`, `AddCounterByLabel(...) (int64, error)` | return `(*Counter, error)` | The registration id is `counter.RegistrationId()`; the counter value is read/written through the returned `*Counter` (embeds `*counters.AtomicCounter`). Close it with `counter.Close()`. |
| `(*ClientConductor).AddPublication/AddExclusivePublication/AddSubscription/AddSubscriptionWithHandlers` returned the registration id `(int64, error)` | return the object (`*Publication`, `*ExclusivePublication`, `*Subscription`) | Only affects code driving the conductor directly; use `Aeron.Add*` / `AsyncAdd*` + `Get*` instead. |
| `(*Context).AvailableCounterHandler(h)` / `UnavailableCounterHandler(h)` returned nothing | return `*Context` | Chaining now works; no change needed unless you implemented an interface with the old signature. |
| `Image` interface | gained `BlockPoll`, `BoundedControlledPoll`, `ControlledPeek`, `EndOfStreamPosition`, `InitialTermID`, `IsPublicationRevoked`, `JoinPosition`, `MtuLength`, `PositionBitsToShift`, `RawPoll`, `Reject`, `SetPosition`, `SourceIdentity`, `SubscriberPositionID`, `Subscription` | Custom `Image` implementations (test fakes) must add these; regenerate mocks (`aeron/mock_image.go` is generated by mockery). |
| `DriverProxy.RemovePublication(id) error`, `RemoveSubscription(id) error` | `RemovePublication(id, revoke bool) (int64, error)`, `RemoveSubscription(id) (int64, error)` | Return the correlation id of the remove command. `revoke` maps to Java `Publication.revoke`. Also on `driver.Proxy`. |
| `DriverProxy` interface | gained `AddStaticCounter`, `AddStaticCounterByLabel`, `NextAvailableSessionID`, `RemoveDestinationByID` | Custom implementations must add them. |

## `aeron/command`, `aeron/driver` (driver protocol flyweights)

* `command.*Message` flyweights (`CorrelatedMessage`, `CounterMessage`, `DestinationMessage`, `ImageMessage`,
  `PublicationMessage`, `RemoveMessage`, `SubscriptionMessage`) no longer expose exported `flyweight.Field`
  members (`ClientID`, `CorrelationID`, `Channel`, `StreamID`, ..., `FWBase`) and no longer embed `FWBase`
  (`Size`/`SetSize` are gone). Use the accessor methods; `Wrap(buf, offset)` now returns the concrete message
  pointer instead of `flyweight.Flyweight`. `CounterMessage.CopyKeyBuffer/CopyLabelBuffer/CopyLabelString` were removed.
  (The exported fields cannot be restored: their names collide with the accessor methods.)
* `driver.Events` gained `OnStaticCounter`, `OnPublicationError`, `OnNextAvailableSessionID`; `driver.Listener`
  gained `OnPublicationError` and `OnStaticCounter`.

## `aeron/logbuffer`, `aeron/logbuffer/term`, `aeron/idlestrategy`, `aeron/util`

* `logbuffer.DataFrameHeader` struct gained fields (struct literals that list fields positionally break).
* `LogBufferMetaData.IsConnected` and `PageSize` fields were removed; use the accessor methods on the metadata
  (`IsConnected()`, `PageSize()`), which read the Java layout.
* `logbuffer.RotateLog` returns `bool` (whether the rotation CAS succeeded), matching Java `LogBufferDescriptor.rotateLog`.
* `util.Memcpy` and `util.MemPrint` take `unsafe.Pointer` instead of `uintptr` (so `go vet`/checkptr can track the memory).

## `archive`

| Upstream | parity | What to do |
|---|---|---|
| `(*Proxy).ConnectRequest`, `codecs.ConnectRequest*` | removed | Java 1.53.3 only sends `AuthConnectRequest`. |
| `codecs.AuthConnectRequestPacket(...)` (generated) | extra trailing `clientInfo string` argument | Pass `""` or a client name. `(*Proxy).AuthConnectRequest` keeps the upstream signature. |
| `Control.State`, `PollContext`, `ConnectionControlFragmentHandler`, `DescriptorFragmentHandler` | removed | Connection state is internal (Java `AeronArchive.AsyncConnect`); use `archive.NewArchive` or the async connect API. |
| `(*Archive).AddExclusivePublication` returned `*aeron.Publication` | `*aeron.ExclusivePublication` | As for `aeron`. |
| `Proxy.Publication *aeron.Publication` | `aeron.Publisher` | Field type is now the interface. |
| `(*Proxy).CatalogHeaderRequest` | removed | Not part of the Java 1.53.3 archive client protocol. |
| `RecordingIdNullValue = int32(-1)` | untyped `-1` | Recording ids are `int64`; the untyped constant works for both. Only `x := RecordingIdNullValue` (now `int`) or passing it as `interface{}` changes. |
| `RecordingLengthMax = 4294967295` | `math.MaxInt64` | Java `AeronArchive.NULL_LENGTH`/max length semantics; `StartReplay(..., length)` with `RecordingLengthMax` now replays everything. |

## `archive/replaymerge`

* `(*ReplayMerge).Close()` returns `error`.
* `MergeProgressTimeoutDefaultMs` is `5000` (was `5000000`, i.e. 83 minutes, a unit bug). If you passed it to
  `NewReplayMerge` the merge now fails after 5 s without progress, like Java's `MERGE_PROGRESS_TIMEOUT_DEFAULT_MS`.
* `NewReplayMerge` requires the subscription channel to have `control-mode=manual`, the replay destination may use
  port 0 (resolved before the replay starts) and the state machine (`State()`, `HasFailed()`, `IsLiveAdded()`)
  follows Java. `Poll`/`ControlledPoll` return `(int, error)`; check `HasFailed()` in the poll loop.

## `cluster` (service side)

* `ClusteredService.OnTakeSnapshot(*aeron.Publication)` is now `OnTakeSnapshot(*aeron.ExclusivePublication)`.
* `ClusterSchemaVersion` is 17 (was 8); the codecs in `cluster/codecs` were regenerated from the 1.53.3 schema,
  so a parity service cannot talk to a pre-1.40 consensus module.
* `NewClusterMarkFile(path)` became `NewClusterMarkFile(path, componentType, errorBufferLength)` and
  `(*ClusterMarkFile).SignalReady()` takes the activity timestamp `SignalReady(nowMs int64)`.
* `Leader`, `Follower`, `Candidate` are typed `cluster.Role`.
* `Cluster` interface gained `Aeron`, `ClientSessions`, `CloseClientSession`, `ForEachClientSession`,
  `GetClientSession`, `Options`, `TryClaim`; `ClientSession` gained `IsClosing` and `TryClaim`. Custom
  implementations/fakes must add them.
* `cluster.Options` is no longer comparable (it contains func/slice fields); don't use it as a map key or with `==`.

## `cluster/client`

The client was rewritten after Java `AeronCluster` / `AeronCluster.Context`:

```go
// upstream
opts := client.NewOptions()
opts.IngressChannel = "aeron:udp?alias=cluster-client-ingress"
opts.IngressEndpoints = "0=localhost:20000"
cluster, err := client.NewAeronCluster(aeronCtx, opts, listener)
for !cluster.IsConnected() { cluster.Poll() }

// parity
ctx := client.NewContext()
ctx.AeronDirectoryName = aeronDir // or ctx.Aeron = existingClient
ctx.IngressChannel = "aeron:udp?alias=cluster-client-ingress"
ctx.IngressEndpoints = "0=localhost:20000"
ctx.EgressListener = listener
cluster, err := client.Connect(ctx) // blocks until connected or MessageTimeout; see NewAsyncConnect for polling
defer cluster.Close()
for { cluster.PollEgress(); ... }
```

* `NewAeronCluster`, `NewOptions`, `Options`, `TemporaryError` were removed; use `NewContext` + `Connect`
  (or `NewAsyncConnect(ctx)` + `Poll()`).
* `(*AeronCluster).Poll()` was removed; use `PollEgress()` / `ControlledPollEgress()`.
* `(*AeronCluster).SendKeepAlive() bool` returns `(bool, error)`; `Close()` returns `error`.
* `EgressListener` follows Java: `OnConnect`, `OnDisconnect`, `OnError` were removed (connect errors are returned
  by `Connect`, async errors go to `Context.ErrorHandler`, session close/errors arrive via `OnSessionEvent`).
  `OnMessage(cluster, sessionId, buffer, offset, length, header)` became
  `OnMessage(clusterSessionId, timestamp, buffer, offset, length, header)`;
  `OnNewLeader(cluster, leadershipTermId, leaderMemberId)` became
  `OnNewLeader(clusterSessionId, leadershipTermId, leaderMemberId, ingressEndpoints)`; `OnSessionEvent` and
  `OnAdminResponse` were added. Embed `client.NoOpEgressEvents` and implement only `OnMessage`, or wrap a
  function with `client.EgressListenerFunc`.
* Authentication uses `Context.CredentialsSupplier` (Java `CredentialsSupplier`).

## Behaviour changes that still compile

* `aeron.NewContext()` honours `AERON_DIR` for the default directory, like the C client.
* `Aeron.AddPublication`/`AddSubscription`/`AddCounter` block until the driver answers (use `AsyncAdd*` + `Get*`
  to poll); driver errors are returned as `error` rather than logged.
* Archive request/response, recording signals and errors follow the 1.53.3 protocol (archive errors are returned
  as `*archive.ArchiveException` (alias `ArchiveError`) carrying the Java `ArchiveException` error code).
* `examples` binaries: archive samples default `-prefix` to `/dev/shm/aeron-<user>`; pass the driver directory
  (`/dev/shm/aeron-compose` for the docker harness). Sample output now matches Java's `SamplesUtil`.

## Restored for compatibility

These upstream shapes were changed on `parity` only to look like Java and have been put back; the Java-style
behaviour is available under additive names.

* `aeron.ChannelUri` has value semantics again: `ParseChannelUri(s) (ChannelUri, error)`, value receivers for the
  read methods and `Set`/`Remove`, `Clone() ChannelUri`, `Remove(key)`, `SetMedia(m)`, `SetPrefix(p)` (no returns).
  Copies share their parameters (as with upstream's map) and keep insertion order, so `String()` round-trips the
  parsed order rather than upstream's sorted keys. `Lookup` gives the previous value before a `Remove`; `Put` also
  works on a zero `ChannelUri`, where `Set` panics as upstream did. `SetMedia` no longer validates the media.
* `(*Aeron).AddPublicationDeprecated` / `AddSubscriptionDeprecated` (chan-returning, deprecated).
* `aeron.NewIdAndAvailablePair` / `NewIdAndUnavailablePair`.
* `aeron/command` command type ids and `ErrorCode*` constants are untyped (new ids added for 1.53.3 stay typed).
* `idlestrategy.DefaultMaxYields` is `20` (Java uses `5`).
* `term.ControlledPollActionBreak/Commit/Continue` are untyped; `ControlledPollActionAbort` is typed, as upstream.
* `(*Archive).PurgeRecording(id) error`, `TruncateRecording(id, pos) error`; the deleted segment counts are returned
  by `PurgeRecordingWithCount` / `TruncateRecordingWithCount`.
* `(*Archive).StopRecordingByPublication(aeron.Publication) error`; `StopRecordingByPublisher(aeron.Publisher)`
  takes a `*Publication` or `*ExclusivePublication`.
* `(*Proxy).AuthConnectRequest(corr, stream, ch, creds)`; `AuthConnectRequestWithClientInfo` adds the client info.
* `archive.Options.AuthEnabled/AuthCredentials/AuthChallenge/AuthResponse` (deprecated): with `AuthEnabled` and a
  nil `CredentialsSupplier` the options conclude to `StaticCredentialsSupplier{AuthCredentials, AuthResponse}`, and
  a challenge that differs from a non-nil `AuthChallenge` fails the connect.
* `archive.ControlState*` constants (deprecated, unused).
* `archive.NULL_RECORDING_ID`, `RECORDING_ID_OFFSET`, `SESSION_ID_OFFSET`, `SOURCE_IDENTITY_LENGTH_OFFSET`,
  `SOURCE_IDENTITY_OFFSET`, `RECORDING_POSITION_COUNTER_TYPE_ID` are untyped.

## New functionality (non-breaking)

* `archive/replaymerge`: Java `ReplayMerge` (replay a recording and merge onto the live stream).
* `archive/persistentsubscription`: Java `PersistentSubscription` (start from a recording position, replay,
  join live, fall back to replay on loss).
* `archive`: full `AeronArchive` API (replication, `ListRecording*`, recording signals, `StartRecording` variants,
  migrate/attach/detach segments, `PollForErrorResponse`, async connect, credentials suppliers).
* `aeron`: `ExclusivePublication`, `Publisher`, `Counter`, `TryClaim`/`Claim` flags, `OfferResult` helpers,
  image `Reject`, publication `Revoke`, static counters, response channels (`control-mode=response`).
* Cluster client admin requests, session events, leader redirection; cluster service snapshots, timers,
  multiple services.

See [docs/API_AUDIT.md](docs/API_AUDIT.md) for the remaining known divergences from Java.
